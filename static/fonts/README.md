# Schriften (N8 Theme 2.1)

Selbst gehostet, keine Anfrage an fremde Server. Alle Schriften stehen unter der **SIL Open Font License 1.1** (je Ordner `LICENSE`),
Dateien aus den Fontsource-Paketen 5.3.0, Schnitte 400/600/700, Zeichensätze Latin und Latin-Extended (Deutsch, Umlaute, ß, Akzente).

| Schlüssel | Schrift | Ordner |
|---|---|---|
| `plex` (Standard) | IBM Plex Sans | `ibm-plex-sans/` |
| `inter` | Inter | `inter/` |
| `barlow` | Barlow | `barlow/` |
| `exo2` | Exo 2 | `exo-2/` |
| `rajdhani` | Rajdhani | `rajdhani/` |
| – (Zahlen, Anzeigen, Code) | JetBrains Mono | `jetbrains-mono/` |

Gleich in allen N8-Systemen; eingebunden über `n8-theme.js` (liegt neben diesem Ordner).
